**Тут основа**
Название и версия: NIST SSDF 1.1
Для чего предназначена: фреймворк- модель, задающая структуру организованных практик безопасной разработки.
Почему подходит нашему проекту: дает компактную основу полного жизненного цикла, которую легко встроить в существующий процесс разработки. Тут: подготовка, защита ПО, создание продукта, реагирование.
Что придётся адаптировать: нужно конкретизировать действия, роли (нас всего двое) и артефакты под масштаб MVP.
Что не покрывает: не содержит технических деталей проверок кода и уязвимостей в вебе.
Доступна ли нужная версия: Да, выложена публично.
Предварительное решение: основная рамка.

**Сугубо мое мнение, индивидуальное**
Название и версия: OWASP ASVS 5.0.0
Для чего предназначена: каталог структурированных проверяемых требований для web-приложений.
Почему подходит нашему проекту: содержит конкретные технические ориентиры для проверки API (валидация URL + работа с токенами).
Что придётся адаптировать: нужно отфильтровать только применимые к нашему MVP требования базового уровня (Первого уровня).
Что не покрывает: не является рамочной моделью, не описывает процессы и SDLC.
Доступна ли нужная версия: Да.
Предварительное решение: доп. источник.
